# Parsing and processing entry points

The baseline parsing chapter has been split so that each normative rule has one
owner:

- [Document format](./document.md) defines TOML syntax, document identity,
  encoding, key spelling, and unknown-key handling.
- [Document loading and composition](./loading.md) defines root discovery,
  includes, path provenance, traversal, and merge behavior.
- [Resolution](./resolution.md) defines the source, composed, and resolved
  models and their validation boundaries.

This page is retained as a navigation target for links to the earlier draft. It
does not define additional requirements.
